	// 1) Наследование - создание нового класса на основе уже существующего класса.
	//    Новый класс получает его свойства и методы.

	// 2) Полиморфизм - возможность использовать один и тот же интерфейс
	//    для объектов разных классов, при этом поведение объектов может отличаться.

	// 3) Абстракция - выделение главных свойств объекта и сокрытие
	//    несущественных деталей его реализации.

	// 4) Инкапсуляция - объединение данных и методов работы с ними внутри класса,
	//    а также ограничение прямого доступа к внутренним данным объекта.
*/

// * protected - защищенный (можно изменять в исходном классе и в классе наследника)
